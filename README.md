# OceanBook Pro - マリン観光予約管理アプリ

**バージョン**: v20.0  
**最終更新**: 2026-03-06

---

## 🌊 概要

**OceanBook Pro**は、沖縄・糸満市大度浜海岸での「天然水族感ツアー」運営を支援する、完全フロントエンド型の予約管理アプリケーションです。

---

## ✨ 主な特長

### 📱 完全ローカル動作
- **localStorage**による永続データ保存
- インターネット接続不要（初回読み込み後）
- プライバシー保護（データは端末内に保管）

### 📅 予約管理
- 11項目の詳細予約フォーム
- 複数参加者対応
- ステータス管理（確定・仮予約・キャンセル）
- 編集・削除機能

### 🎽 器材自動判定
- 6種類の器材を自動算出
  - ライフジャケット（身長・体重）
  - フィン（靴サイズ）
  - ブーツ（靴サイズ、5mm単位切り上げ）
  - グローブ（S/M/L）
  - 度付きマスク（視力情報）
  - ウェットスーツ（身長・体重）

### 👥 チーム分け
- 手動割り当て
- 自動割り当て（5つのルール適用）
- ドラッグ＆ドロップ対応

### 💬 LINE会話管理
- 15件の会話を再現
- 未読カウント表示
- 既読管理

### 🌤️ 天気・海況ウィジェット（v20.0 新機能）
- **糸満市大度浜海岸**のリアルタイム情報
- 満潮・干潮（那覇港）
- 日の出・日の入り（計算式）
- 現在の天気・気温
- 波高（m表示）
- 風向・風速
- 週間予報（気象庁API）
- 1時間ごとの自動更新

### 📊 分析・レポート
- 11種類のKPI
- 24種類のグラフ（Chart.js）
- AIマーケティングレポート
- 月次統計
- ガイド別パフォーマンス
